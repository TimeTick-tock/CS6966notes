# 犹他大学 · 大语言模型可解释性（2026）课堂笔记

根据犹他大学Ana Marasović教授2026年春季CS6966（Interpretability of LLMs，大语言模型可解释性）课程的字幕整理的复习笔记。

本笔记通过AI生成。由于技术有限，许多字幕是错的。一些错的字幕已经过原论文核对。

## 课程简介

本课程深入探讨了大型语言模型（LLMs）的内部机制，涵盖了从基础的叠加原理、线性表示假设，到前沿的稀疏自编码器（SAE）、转码器（Transcoders）、归因图（Attribution Graphs）以及激活修补（Activation Patching）等核心概念。

## 目录结构

每一讲通常有两个文件，名字对齐：

- `N-第N讲：…….srt`：字幕。
- `N-第N讲：……-课堂笔记.md`：笔记。

克隆仓库：

